# HORUS Arbitrage Bot — v0.1

Objetivo: construir primero un scanner/paper trader de arbitraje, sin dinero real.

Capital objetivo posterior:
- Capital inicial: US$100
- Aportes externos: US$0
- Ganancias: reinversión automática

Primera versión:
1. Obtener mercados.
2. Obtener precios/order book.
3. Detectar arbitrajes internos.
4. Calcular margen neto.
5. Registrar oportunidades.
6. Paper trade.
7. Medir capturabilidad y duración.
8. Solo después evaluar ejecución real.

La conexión live y la ejecución de órdenes quedan deliberadamente fuera de v0.1.
